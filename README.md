# nonebot-plugin-bili-fans-overlap

NoneBot2 插件：查询 B 站粉丝团之间的 UID 重合率。

## 使用

```text
/粉丝团查重 小礼猫 酷萨 音悦生
```

一次最多查询 5 个粉丝团。名称必须与插件内 `rooms.json` 中的 `medal` 完全一致，至少输入 2 个名称。

结果会先列出每个粉丝团的 UID 总数，再按方向计算比例：`A&B` 表示 B 与 A 的交集占 A 的比例，即交集 UID 数除以 A 的 UID 数，并保留两位小数。同一对粉丝团会输出两个方向：

```text
粉丝团重合查询
小礼猫总数：1234
酷萨总数：2234
小礼猫&酷萨：33.33%
酷萨&小礼猫：35.33%
```

详细双牌子查重只接受两个粉丝团名称：

```text
/粉丝团查重详细 小礼猫 酷萨
```

详细结果会按方向输出交集、每 10 级一档的粉丝牌等级、舰长/提督/总督数量及比例。每一行的比例都以行首粉丝团总数为分母；数量为 0 的等级和身份分桶不显示，但双向交集与 `小礼猫&酷萨共同上舰` 三行始终显示。共同上舰统计两个粉丝团 `guard_level` 相同且非零的 UID。结果末尾固定追加当前牌子名称对应的统计口径说明。

单个粉丝团详细信息只接受一个完整名称：

```text
/粉丝团详细 小礼猫
```

结果会输出粉丝团总数、每 10 级一档的等级分布、上舰总数和舰长/提督/总督数量。等级比例以粉丝团总数为分母，上舰身份比例以上舰总数为分母；数量为 0 的行不显示，并正常回复消息。

粉丝团列表命令会列出当前 `rooms.json` 中所有可查询的主播名称和粉丝牌名称：

```text
/粉丝团列表
```

列表会通过合并转发发送，内容格式为 `主播名称 粉丝牌名称`。

## 配置

在 NoneBot 宿主的 `.env` 中可配置：

```dotenv
BILI_FANS_OVERLAP_API_BASE=https://fans.harei.cn
BILI_FANS_OVERLAP_HTTP_TIMEOUT=10
```

插件会请求 bilifanscache 的 `/fans?room_id=<room_id>` 接口获取缓存的粉丝 UID。
